# Security Policy

## Scope and status

GroundStack is experimental and is not suitable for exposure to untrusted networks or sensitive production workloads. Current known limitations include development service credentials in Compose, disabled OpenSearch security in the local topology, and API routes without authentication or document-level authorization.

## Reporting a vulnerability

Please do not open a public issue for an exploitable vulnerability. Contact the repository maintainers through the private security reporting mechanism provided by the hosting platform. Include affected version/commit, impact, reproduction steps, and any suggested mitigation. Do not include private documents or real credentials.

There is no guaranteed response SLA yet. Please allow maintainers time to investigate and coordinate a fix before public disclosure.

## Supported versions

No stable release has been published. Security fixes target the current `main` branch.
