# Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community for everyone.

Be considerate, use inclusive language, accept constructive criticism, and focus feedback on the work. Harassment, discriminatory conduct, personal attacks, and unwanted sexual attention are not acceptable.

Project maintainers may remove, edit, or reject contributions that violate this standard and may temporarily or permanently exclude contributors from project spaces. Report concerns privately to the repository maintainers. This policy is adapted from the Contributor Covenant, version 2.1.
