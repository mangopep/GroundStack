# Glossary

- **BM25:** lexical ranking that scores query/document term overlap.
- **Chunk:** a smaller passage produced from a document for indexing/retrieval.
- **Docling:** PDF/document conversion library used by the parser.
- **Embedding:** vector representation of text from an embedding model.
- **Evidence coverage:** proportion of answer claims with relevant cited evidence.
- **Manifest:** canonical record of a source document, version, job state, and derived artifacts; not implemented.
- **RAG:** retrieval-augmented generation, a retrieve-then-generate pattern.
- **RRF:** Reciprocal Rank Fusion, a method to combine ranked result lists.
- **Tenant isolation:** controls that prevent one user/group from reading another's data; not implemented.
