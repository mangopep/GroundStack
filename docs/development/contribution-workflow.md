# Contribution workflow

Use the existing [CONTRIBUTING.md](https://github.com/mangopep/rag_platform/blob/main/CONTRIBUTING.md), issue templates, and pull-request template. Recommended stages are issue/acceptance criteria → focused branch → implementation and tests → docs review → CI → maintainer review → release note when user-visible.

Branch protection and required-review settings are recommendations only; repository settings were not changed in this audit. Keep commits focused. Do not push to protected branches, publish releases, or rewrite history without explicit authorization.
