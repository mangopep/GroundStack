# Evaluation

No retrieval or answer benchmark is currently available. There is no supported evaluation harness, corpus, label set, reproducible command, model configuration, or measured output. RAGAS was removed from dependencies after its dependency graph triggered a security advisory; do not infer quality from a package name or script.

Define a licensed corpus and human relevance labels before reporting retrieval quality. Keep retrieval metrics separate from answer faithfulness and citation correctness. See [benchmark methodology](benchmarks.md).
