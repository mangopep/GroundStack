# Evaluation methodology

No GroundStack benchmark results are currently available. A reproducible run must record commit, OS/CPU/accelerator, memory, Docker and model versions, corpus license/hash, parser/chunker/index settings, warm/cold status, concurrency, and repetitions. Separate retrieval metrics from generation: Recall@K, MRR, nDCG; citation correctness, evidence coverage, faithfulness, abstention quality; ingestion throughput, p50/p95 latency, and peak RSS/container memory. Publish raw labels and scripts where licensing permits. Mark unavailable measurements NOT TESTED.
