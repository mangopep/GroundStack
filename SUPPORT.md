# Support

This is an experimental open-source project with no commercial support or response-time commitment.

- Use GitHub Issues for reproducible bugs and feature proposals.
- Use GitHub Discussions (if enabled) for design questions and usage help.
- For security issues, follow [SECURITY.md](SECURITY.md) instead of posting details publicly.

Include the commit, Python/OS versions, exact command, sanitized logs, and whether external services were involved. Never upload private source documents, credentials, or database dumps.
